# Car Price Prediction Project

# Overview
The Car Price Prediction project aims to predict the selling price of cars based on various features such as fuel type, selling type, transmission, and other relevant attributes. This project utilizes machine learning techniques, specifically Linear Regression and Lasso Regression, to build predictive models.

# Project Structure
```
car-price-prediction
├── main.ipynb          # Main code for the car price prediction project
├── data                # Directory containing the dataset
│   └── car data.csv    # Dataset used for training the model
├── requirements.txt    # List of required Python packages
└── README.md           # Documentation for the project
```

# Files Description
- **main.ipynb**: This Jupyter Notebook contains the complete workflow for the car price prediction project, including data acquisition, preprocessing, visualization, and model training.
  
- **data/car data.csv**: This CSV file contains the dataset used for the prediction model, featuring various attributes related to cars.

- **requirements.txt**: This file lists the necessary Python libraries to run the project, including:
  - pandas
  - matplotlib
  - seaborn
  - scikit-learn

# Installation Instructions
1. Clone the repository:
   ```
   git clone : 
   ```
2. Navigate to the project directory:
   ```
   cd car-price-prediction
   ```
3. Install the required packages:
   ```
   pip install -r requirements.txt
   ```

# Usage
1. Open the `main.ipynb` file in Jupyter Notebook or any compatible environment.
2. Run the cells sequentially to execute the data processing and model training steps.
3. Analyze the results and visualizations generated by the notebook.
